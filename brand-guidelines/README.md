# YoByTech Brand Guidelines

Brand guidelines for **YoByTech Automation** (yobytech.com) and its healthcare product **YoDr** (yodr.live).
Colors, fonts, button and card styles were measured from the live sites on 2 November 2026.

Open `index.html` in a browser. It covers:

- Naming and endorsement rules for both brands
- Logo usage, clear space, minimum sizes and misuse
- Color palettes with usage ratios (click a swatch to copy its hex)
- Typography scales and specimens
- Live component examples (buttons, cards, tags, pricing)
- Voice and imagery rules
- WCAG contrast checks and a prioritised fix list for the live sites
- Copy-ready CSS design tokens

## Editing

Edit `src/index.template.html`, then rebuild (needs Python 3 and Pillow):

```bash
python3 build.py
```

This embeds the logos from `assets/` into `index.html` so the page works as a single file.
