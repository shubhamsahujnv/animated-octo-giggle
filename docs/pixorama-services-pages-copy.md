### FAQ

**What are AI development services?**
Design and engineering of AI systems into a product — retrieval, agents, model integration and the data
work underneath. The distinction worth drawing is between *using* an AI tool and *building* an AI system:
we do the second, which is what you need when the AI has to work on your data, in your product, reliably.

**RAG or fine-tuning — which do we need?**
Usually RAG. Fine-tuning changes how a model writes; retrieval changes what it knows. Most business
problems are knowledge problems, so retrieval solves them more cheaply and updates instantly when your
data changes. We cover the full trade-off in [RAG vs fine-tuning](/blog/rag-vs-fine-tuning).

**How do you stop it hallucinating?**
You don't eliminate it; you constrain and measure it. Grounding answers in retrieved sources, citing those
sources back to the user, refusing when confidence is low, and running an evaluation set on every change
so you can see accuracy move. Any agency promising zero hallucination is selling you something.

**What does an AI project cost to run, not just to build?**
Inference costs are real and they scale with usage, so we model them during feasibility and build in
caching and routing to control them. You should know your per-query cost before launch, not after the
first invoice.

**Is our data used to train anyone's model?**
Not under our builds. We use enterprise API tiers with training disabled by default, and for sensitive data
we can deploy open-weight models in your own infrastructure. [CONFIRM: your actual DPA position.]

**How long until we see something working?**
A feasibility result in [CONFIRM: 1–2 weeks], and a working increment every two weeks after that.

### FAQ

**What does a web development agency do that a website builder doesn't?**
Builders are fine for a brochure site. You need an agency when the site has to do something — integrate
with your systems, scale, rank competitively, or convert at a rate you're measuring. The difference shows
up in performance, SEO foundations and what happens when you need to change something non-trivial.

**How long does a website take to build?**
[CONFIRM: typically 4–10 weeks] depending on page count, CMS requirements and integrations. Audits and
performance work on an existing site are faster — often [CONFIRM: 2–3 weeks].

**Do you do SEO as well as development?**
Yes, and we'd argue they shouldn't be separated. Most SEO problems are engineering problems: site
architecture, rendering, crawl budget, page speed, structured data. An SEO agency that can't change your
code is limited to recommending things.

**How long until we see SEO results?**
Technical fixes can move things within weeks. Ranking for competitive commercial terms takes months — three
to six before meaningful movement, longer for a new domain with little authority. Anyone promising page one
in thirty days is describing a term nobody searches for.

**Will the site be fast on mobile?**
That's the target we build to. Core Web Vitals in the "good" range on real mobile devices, not just on a
desktop test. Mobile is where most sites lose, and where most of the traffic is.

**Can you work on our existing site instead of rebuilding?**
Usually, and often it's the better call. The audit tells us whether the foundations are sound enough to
build on. We'll give you the honest comparison including cost.

## Schema markup

Each service page needs three blocks: `Service`, `BreadcrumbList` and `FAQPage`. One worked example
below — repeat the pattern per page, changing `name`, `description`, `url` and the FAQ entries.

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Service",
      "name": "Custom Software Development",
      "serviceType": "Custom Software Development",
      "description": "Custom software built to production — SaaS platforms, MVPs, internal systems and legacy modernisation.",
      "url": "https://pixoramagroup.com/services/custom-software-development",
      "provider": {
        "@type": "Organization",
        "name": "Pixorama Group",
        "url": "https://pixoramagroup.com"
      },
      "areaServed": [
        { "@type": "Country", "name": "United States" },
        { "@type": "Country", "name": "Australia" }
      ]
    },
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        { "@type": "ListItem", "position": 1, "name": "Home", "item": "https://pixoramagroup.com/" },
        { "@type": "ListItem", "position": 2, "name": "Services", "item": "https://pixoramagroup.com/services" },
        { "@type": "ListItem", "position": 3, "name": "Custom Software Development", "item": "https://pixoramagroup.com/services/custom-software-development" }
      ]
    },
    {
      "@type": "FAQPage",
      "mainEntity": [
        {
          "@type": "Question",
          "name": "How much does custom software development cost?",
          "acceptedAnswer": {
            "@type": "Answer",
            "text": "It depends on scope, but we give you a fixed number at the end of discovery rather than an hourly rate and hope."
          }
        }
      ]
    }
  ]
}
```

Add `Organization` schema once, sitewide, in the layout — not repeated per page.
