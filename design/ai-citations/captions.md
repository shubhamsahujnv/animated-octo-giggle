## Accessibility note

Unicode bold is not real bold. Most screen readers either skip these
characters or read them out as "mathematical sans-serif bold a", so anything
set in bold is effectively lost to assistive tech. Each caption above is
written so the sentence still reads correctly if the bold characters are
dropped, and no fact appears only in bold. If accessibility outranks visual
emphasis for a given channel, strip the bold and post plain text.
