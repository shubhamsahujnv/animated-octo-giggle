Make the app easier to scan by shortening verbose or awkward interface text without changing meaning, workflow, calculations, data, or visual design.

## Changes
- Edit only user-facing wording in the existing static app.
- Tighten labels, helper text, instructions, empty states, prompts, and alerts.
- Preserve technical terms, methodology descriptions, references, legal meaning, and all functional values.
- Keep the current structure, styling, controls, and behavior unchanged.

## Validation
- Confirm the page still loads and signs in normally.
- Check key views and forms for missing text, broken controls, or changed behavior.
- Verify the app remains a complete static HTML document.

## Technical details
